# Voting guide rules

Output: `malden-w3p2-<election>.md` + optional wordy `...-notes.md`. No version suffixes; revisions go in git commits.

## Content priority
1. Debates / forums: links to watchable or downloadable video/audio. This is most of the value.
2. Primary sources: official text, candidate sites, filings, poll releases.
3. Analysis only if it links to the specific finding and the finding is not marginal. Else omit.

## Do not include
- Endorsements (any kind: editorial, politician, org).
- Win / pass probabilities.
- Prose summaries of analysis. A link label of 1–3 words is enough.

## Format
- Races and questions in ballot order.
- Tie probability per race (math lives in notes file). Effort ∝ tie probability: close races get more digging, landslides get one line.
- Link labels terse: `[debate Oct 21](url)`, not sentences.
- Every factual claim is a link to its evidence.
